## 🎯 What Happens Automatically

**Every weekday at 9:00 AM IST (Mon-Fri):**

1. GitHub Actions runs Python screener
2. Scans 50+ NSE stocks for EDGE PROTOCOL signals
3. Calculates EMA, RSI, Supertrend, Volume indicators
4. Filters results (all 5 conditions must pass)
5. Saves matching stocks to `results.json`
6. Auto-commits to git history
7. Website updates live (no refresh needed)

## ⚙️ Quick Customizations

### Change scan time:
Edit `.github/workflows/screen.yml` line 8
```yaml
- cron: '30 3 * * 1-5'  # 9 AM IST
```
Use [crontab.guru](https://crontab.guru) for your timezone.

### Add/remove stocks:
Edit `screener.py` line 15
```python
NSE_STOCKS = [
    'RELIANCE.NS', 'TCS.NS',  # Add/remove tickers
]
```

### Adjust filters:
Edit `screener.py` function `apply_filters()` (line ~80)
```python
rsi_ok = (50 < ind['rsi'] < 75)  # Change thresholds
```
